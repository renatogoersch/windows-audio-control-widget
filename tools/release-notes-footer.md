## Qual zip baixar

| Arquivo | Tamanho | Requisito |
|---|---|---|
| `SlotMixer-requer-dotnet.zip` | ~0,1 MB | [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64) instalado |
| `SlotMixer-autonomo.zip` | ~58 MB | nenhum (leva o .NET dentro) |

Cada zip traz o `SlotMixer.exe` e um `LEIA-ME.txt` em português. Na primeira abertura o exe oferece instalar; quem já tem o SlotMixer instalado recebe esta versão sozinho.

## Avisos

- O exe **não é assinado**: o Windows SmartScreen avisa na primeira vez ("Mais informações" › "Executar assim mesmo").
- Testado no Windows 11 (build 26200), com 1 monitor. A troca de saída por app usa uma API interna do Windows, que pode mudar entre versões.
